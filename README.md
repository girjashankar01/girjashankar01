## Projects

- **[xBOM](https://github.com/girjashankar01/xBOM-system)**: generates software and cryptography inventories from source using AST parsing, with post-quantum support. Ranks vulnerabilities from critical to low, links each CVE with how it was fixed, and uses a vector-RAG check to show what's wrong, where, and what to change and why.
- **[SafeGo](https://github.com/girjashankar01/safe-Go-app)**: women's safety app with live location sharing to trusted contacts. Its SOS emails send the last location, the nearest police station, a custom-length audio recording and medical info.
- **[AI Hallucination Detector](https://github.com/girjashankar01/AI-Hallucination-Detector-2.0)**: RAG pipeline that verifies LLM answers with domain-specific embedders (medical, legal, finance, general) and offline model fallback. It scores claims by NLI (40%), consistency (35%), grounding (15%) and embedding similarity (10%).
